# 🤖 Nolan 语音助手

一个运行在本地 Windows 机器上的中文语音助手，助手自称 **Nolan**，称呼用户「先生」：
**对着麦克风说话 → Whisper 识别 → 大脑决策（可调工具）→ 固定音色语音播报。**

阶段一打通「耳朵 → 大脑 → 嘴巴」闭环；阶段二给 Nolan 装上「手」——
大脑不再只输出文本，而是能调用工具执行真实动作（开应用、查网页、读写文件、跑受限命令）；
阶段三补上「记忆」——长期记忆落盘，跨会话认识主人；
阶段四让 Nolan「主动」——到点提醒不用你开口，并用 tkinter 聊天窗口把它包装成可双击启动的软件。

## 快速开始

```bash
# 方式一（推荐）：双击工作区根目录的 Nolan.bat —— 软件窗口
#   打开 tkinter 聊天窗口：可以在输入框打字，也可以点 🎤 直接说话
# 方式二：双击 Nolan-CLI.bat —— 旧控制台语音模式
# 方式三：纯文本测试模式（无需麦克风，直接用键盘打字对话）
python jarvis/jarvis.py --text

# 免麦克风自动测试（退出码 0 表示全部通过）
python jarvis/test_jarvis.py

# memory 模块契约形态自检
python jarvis/selftest_memory_contract.py

# reminders 模块契约形态自检
python jarvis/selftest_reminders_contract.py

# hands · open_app 契约形态自检
python jarvis/selftest_openapp_contract.py
```

唤醒词：以「Nolan」（大小写不敏感）或「诺兰」开头即可；旧名「贾维斯」不再作为唤醒词。
对话中说出「退出 / 再见」等指令即可结束；也可以按 `Ctrl+C` 优雅退出（会语音道别）。

## 人格

Nolan 的人格定位是「贾维斯式可靠管家」（参考贾维斯与《是大臣》汉弗莱的得体与严谨）：

- **正式、精确、简练**：措辞得体不啰嗦，称呼用户「先生」；
- **先确认后执行**：涉及写、删、改等有影响的操作，先复述意图、征得确认再动手；
- **如实汇报**：做了什么、结果如何、哪里失败，原原本本说清楚，不粉饰；
- **承认无知**：不知道就直说不知道，绝不编造；
- **不搞笑**：不讲笑话、不卖萌、不玩梗——可靠是唯一的幽默。

## 网页版

Nolan 还有一个浏览器版（React + Vite 前端 + Python 标准库 API 后端，代码在 `nolan-web\`）：

```bash
# 方式一（推荐）：双击工作区根目录的 Nolan-Web.bat —— 一键同启前后端，
#   并在 5 秒后自动用系统默认浏览器（Chrome / Edge）打开页面
# 方式二：手动启动（先启动 Python 后端，再启动 Vite 前端）
cd nolan-web && npm run dev
```

启动后浏览器打开 Vite 提示的地址（默认 http://localhost:7100/）：

- 🎛️ **NEGA 风界面**：黑底全屏、细体「NOLAN」标识、中央声波可视化、字幕式对话呈现；
- 🎤 语音输入为**服务端录音**：点 🎤 开始、再点停止，无需任何浏览器权限，内嵌窗口也能用。
  麦克风属于机器不属于浏览器——后端直接用 sounddevice 录音 + 本地 faster-whisper 识别，
  前端只当遥控器，不依赖任何外部语音服务；
- 🔊 **发声三级链，男声必达**：主通道为 **GLM-TTS 男声**（智谱 glm-tts，与大脑同一家
  服务商、同一把 API Key，网络稳定、音色统一）；GLM-TTS 不可用时自动降级
  **edge-tts（zh-CN-YunjianNeural 云健男声）** 备用；再不可用则 **Windows SAPI
  离线语音兜底**——三级链路逐层接管，播报永不缺席；
- 🔈 **回复和闹钟会直接在浏览器里播放声音**：`/api/chat` 与 `/api/due` 响应携带
  合成并缓存（`jarvis\files\tts_cache\`，按内容 sha1 命名，重复文本零延迟）
  的音频 URL（GLM-TTS 为 .wav，edge-tts 为 .mp3），前端用 `<audio>` 自动播放
  （与页面交互过一次后浏览器即允许自动播放）；
  服务端音箱同步兜底播报，闹钟到点两边一起响、响两遍。
- 🔊 **声音测试按钮**：右上角细线「声音」按钮（Volume2 图标），点击后调用
  `GET /api/sound_test`，Nolan 会**同时从浏览器和音箱**说同一句话——
  一键验证发声链是否完好，并在对话里插入一条提示消息。
- 🖼️ **网页背景**：`set_web_background` 工具把沙盒中的图片写入
  `jarvis\files\web_background.json`，后端 `GET /api/background` 返回当前背景图
  （图片经 `GET /api/files/<路径>` 提供）；前端自动轮询该端点并即时应用为聊天背景，
  无需刷新页面。背景之上叠加**深色遮罩**，保证对话文字在任何图片上都清晰可读。

┌────────────┐    ┌────────────┐    ┌────────────┐
│   耳朵     │ →  │    大脑    │ →  │    嘴巴    │

│ 麦克风录音 │    │ 意图解析   │    │ edge-tts   │
│ faster-    │    │ 规则 / LLM │    │ 合成 + 播放│
│ whisper 识别│   │            │    │            │
└────────────┘    └─────┬──────┘    └────────────┘
        ↑               │ 调用工具 / 读写记忆 / 管提醒
        │        ┌──────▼──────┐    ┌────────────┐    ┌────────────┐
        │        │     手      │    │    记忆    │    │    提醒    │
        │        │  hands.py   │    │ memory.py  │    │reminders.py│

模块职责与接口契约（签名固定）：

| 模块 | 接口 | 说明 |
| --- | --- | --- |
| `ears.py` | `listen_once(timeout: float = 30.0) -> str \| None` | 阻塞监听一句话，返回识别文本；超时或纯静音返回 `None` |
| `brain.py` | `think(user_text: str, history: list[dict]) -> str` | 返回回复文本；返回 `'__EXIT__'` 表示退出；内部经 `_parse_intent` 识别工具意图并调用 `hands`，识别记忆意图并调用 `memory` |
| `hands.py` | `list_tools() -> list[dict]` / `execute(name: str, args: dict) -> str` | 工具表查询与工具执行；返回可直接语音播报的中文文本，永不抛异常 |
| `memory.py` | `load() -> str` / `remember(fact: str) -> str` / `recall() -> str` / `forget(keyword: str) -> str` | 长期记忆的读取 / 追加 / 口语化列出 / 按关键词删除；`load` 永不抛异常 |
| `reminders.py` | `add(raw: str) -> str` / `list_pending() -> str` / `check_due() -> list[str]` / `parse_time(text: str) -> datetime \| None` | 主动提醒：解析中文时间表达式、落盘未来提醒、到点弹出播报文本 |
| `mouth.py` | `speak(text: str) -> None` | 固定中文音色合成并播放，播完才返回 |
| `jarvis.py` | `main()` | 主循环：欢迎 → 监听 → 思考（含工具与记忆）→ 播报，维护最近 20 轮历史 |
| `nolan_app.py` | 图形窗口入口 | tkinter 聊天窗口：打字 / 🎤 说话两种输入，复用同一条大脑链路，由 `Nolan.bat` 双击启动 |
| `test_jarvis.py` | `main()` | 免麦克风自动测试（大脑断言 + TTS→ASR 回路 + 工具链路 + 记忆链路 + 提醒链路） |
| `selftest_memory_contract.py` | `main()` | memory 模块契约形态自检（函数存在性 + 签名参数名 + 备份还原） |
| `selftest_reminders_contract.py` | `main()` | reminders 模块契约形态自检（函数存在性 + 签名参数名 + 返型抽查 + 备份还原） |
| `selftest_openapp_contract.py` | `main()` | hands · open_app 契约形态自检（execute 签名 + list_tools 9 个工具 + open_app 描述含 VSCode） |

## 能干什么（通用 AI 助手 + 「手」的 13 个工具）

Nolan 是**通用 AI 助手**：写作、翻译、计划、编程、分析等——任何现代 AI 能做的事，
它都会尽力完成，能力不限定于某张固定清单。面对复杂任务，大脑会自动进入
**Agent 循环**：把任务拆解为多步工具链（最多 4 步），每步工具的执行结果回灌给
LLM 继续推理，直到任务完成或给出如实结论。

**复合任务由 Agent 循环自动串联**，无需先生分步指挥。例如
「把网易云音乐我喜欢列表第一首歌的封面设为聊天背景」，Nolan 会自己规划：
`open_app` / `gui_control` 打开应用并定位到目标界面 → `capture_screen`
截取封面存为图片 → `set_web_background` 设为聊天背景，全程如实汇报每一步。

「手」的 13 个工具是它行动力的物理延伸：

| 工具 | 说明 | 语音指令示例 |
| --- | --- | --- |
| `open_app` | 通用应用打开：别名（vscode / 浏览器 / 微信等）+ PATH 查找 + 已知安装路径 + 开始菜单递归搜索；支持模糊说法（如「chrome浏览器」「微信电脑版」），覆盖开始菜单和桌面快捷方式 | 「Nolan，帮我打开VSCode」 |
| `open_url` | 用默认浏览器打开指定网址 | 「Nolan，打开网址 bing.com」 |
| `web_search` | 打开必应搜索关键词 | 「Nolan，搜索明天的天气」 |
| `fetch_url` | 抓取网页正文，返回前 800 字摘要 | 「Nolan，帮我看看这个网页讲了什么」 |
| `read_file` | 读取沙盒目录下的文件（截断 1000 字） | 「Nolan，读一下购物清单」 |
| `write_file` | 往沙盒目录写文件（UTF-8 覆盖写） | 「Nolan，记一下：明天买牛奶」 |
| `list_files` | 列出沙盒目录里的文件 | 「Nolan，我都记了哪些东西」 |
| `run_shell` | 通用 shell 执行：可构造执行本机任意 cmd / PowerShell 命令（输出截断 1000 字）；三级安全闸——只读类直接执行 / 写删改类需先生确认 / 灾难命令直接拒绝 | 「Nolan，看看 C 盘还剩多少空间」 |
| `get_time` | 报告当前时间、日期、星期 | 「Nolan，现在几点」 |
| `media_control` | 媒体控制：播放暂停 / 切歌 / 音量 / 静音（Windows 媒体键，ctypes 零依赖） | 「Nolan，下一首」 |
| `gui_control` | 屏幕感知 + 界面操作：截屏给视觉模型理解，再用鼠标键盘自动化完成软件界面内的操作（执行前会请求确认） | 「Nolan，播放网易云喜欢列表的第一首歌」 |
| `capture_screen` | 通用截屏元素：全屏截图 + glm-4v-flash 视觉定位任意界面元素，裁剪后存为图片（保存到 `jarvis\files\captures\`） | 「Nolan，截取网易云喜欢列表第一首歌的封面」 |
| `set_web_background` | 把沙盒中的图片设为网页版聊天背景（写入 `jarvis\files\web_background.json`，网页端自动轮询应用） | 「Nolan，把刚才截的封面设为聊天背景」 |

## 记忆（长期记忆）

Nolan 能把主人亲口交代的事实记到本地文件里，跨会话生效：

| 意图 | 语音指令示例 | 说明 |
| --- | --- | --- |
| 记住 | 「Nolan，记住我喜欢深蓝色」 | 追加一条记忆，带时间戳 |
| 回忆 | 「Nolan，你记得什么」 | 口语化列出全部记忆并播报 |
| 忘掉 | 「Nolan，忘掉深蓝色」 | 删除所有含该关键词的记忆 |

- **存储位置**：`jarvis\memory\long_term.txt`，UTF-8 编码，每行一条，
  格式为 `[YYYY-MM-DD HH:MM] 内容`。
- **设计取舍（第一性原理）**：纯文本追加 + 关键词匹配删除，不做向量检索、
  不做自动摘要——能用一行解决的事，绝不引入新框架。
- 可以直接用记事本打开该文件查看或手工编辑，重启后仍然生效。

## 主动提醒

Nolan 能记住主人交代的待办，到点不用开口就主动语音播报：

| 意图 | 语音指令示例 | 说明 |
| --- | --- | --- |
| 新增提醒 | 「Nolan，提醒我十分钟后喝水」 | 解析时间前缀 + 内容，落盘一条未来提醒 |
| 新增提醒 | 「Nolan，提醒我明天早上九点开会」 | 支持「明天早上 / 下午 / 晚上 + 几点」这类说法 |
| 闹钟 / 叫醒 | 「Nolan，1分钟后叫醒我」 | 「叫醒我 / 叫我起床 / 闹钟」等说法同样进入提醒系统 |
| 闹钟 / 叫醒 | 「Nolan，明天早上七点半叫我起床」 | 无具体内容时默认播报「起床啦，先生」 |
| 查看提醒 | 「Nolan，我的提醒」 | 口语化列出所有未来提醒 |

- **到点播报**：主循环每轮监听后检查一次到期提醒，到点自动弹出并**连续语音播报两遍**
  （闹钟式重复，确保先生听得到），播报后该提醒即从存储中移除（一次性提醒）。
- **存储位置**：`jarvis\memory\reminders.txt`，UTF-8 编码，每行一条，
  格式为 `YYYY-MM-DDTHH:MM|内容`。
- **设计取舍（第一性原理）**：只做一次性提醒，不做重复规则（每天 / 每周）、
  不做系统托盘与后台常驻——主循环活着，提醒就活着。

## 安全边界

- **文件沙盒**：`read_file` / `write_file` / `list_files` 只能操作 `jarvis\files\` 目录，
  文件名经路径穿越防护（拒绝 `..`、绝对路径、盘符），无法读写沙盒以外的任何文件。
- **命令三级安全闸**：`run_shell` 可执行本机任意 cmd / PowerShell 命令，按风险分级——
  `safe`（只读查询类）直接执行；`confirm`（写、删、改类）先返回待确认提示，
  先生确认后才执行；`blocked`（`format`、`del /f /s C:\` 等灾难级命令）直接拒绝。
  安全闸是可靠性的组成部分，不是累赘。
- **工具执行永不抛异常**：任何失败都返回「抱歉先生，……」的可播报文本，不会中断主循环。

## 能力边界

可靠管家的另一半，是知道自己什么该做、什么绝不做，并如实说明：

- **能操作软件界面**：阶段五起，Nolan 可以截屏看懂屏幕内容，并通过鼠标键盘自动化
  进入软件界面内部操作——例如「播放网易云喜欢列表的第一首歌」，它会一步步看屏幕、
  点选执行，并如实汇报每一步的结果；目标应用未启动时，gui_control 会自动检测窗口、
  打开应用并等待其出现置前，无需先生或 LLM 先开路。
- **界面操作的硬禁止事项**（写死在感知 prompt 里，绝无例外）：输入密码、支付、
  删除文件、向联系人发消息。这类操作 Nolan 会礼貌拒绝，请先生亲自动手。
- **随时可中止**：`gui_control` 执行期间，把鼠标甩到屏幕任意角落即可立即中止
  （pyautogui FAILSAFE）；执行前有步数上限，且整个任务必须先经先生确认才动手。
- **如实汇报，绝不谎称**：工具执行失败会原原本本说清失败在哪，不会用一句
  「执行完毕」粉饰；不知道的事直说不知道，绝不编造。

## 云端大脑（已接入智谱 GLM-5.2）

配置采用「环境变量优先 + 配置文件兜底」双通道——环境变量依赖父进程环境
（旧进程拉起的子进程读不到新值），配置文件任何启动方式都生效。

**主配置：`jarvis/llm_config.json`**（环境变量缺失时自动读取）：

```json
{
  "api_key": "（智谱 API Key）",
  "base_url": "https://open.bigmodel.cn/api/paas/v4",
  "model": "glm-5.2",
  "extra_body": "{\"thinking\": {\"type\": \"disabled\"}}"
}
```

**覆盖用环境变量**（优先级高于配置文件）：`JARVIS_API_KEY` / `JARVIS_BASE_URL` /
`JARVIS_MODEL` / `JARVIS_EXTRA_BODY`。

选型备注：`glm-5.2` 默认开启思考（语音场景下 9s+ 且易截断为空），必须用
`extra_body` 关闭思考后约 3s 可用；追求极速可改回免费的 `glm-4-flash`（约 2s）。
Coding 套餐用户需把 base_url 改为 `/api/coding/paas/v4`。

  升级为 glm-4.5v（已关闭思考模式，实测约 1.8s 响应且准确），具备更强的界面理解与
  导航能力；glm-4.5v 不可用时自动降级 glm-4v-flash 兜底，视觉链路不断线。
- **gui_control 自动开应用前导**：执行界面任务时，gui_control 会自动检测目标应用窗口
  （按窗口标题匹配），缺失时自动打开应用、等待窗口出现并切到前台，无需用户或 LLM
  先用 open_app 开路，杜绝「应用没开就动手、直接报告失败」；
  「打开执行」这类动词残留会被 open_app 意图过滤，不会被误当成应用名。
- **GUI 任务失败如实且具体**：界面任务失败时会明确说明卡在第几步、当时屏幕上看到
  什么，绝不只报一句「执行失败」；步数上限已由 8 步放宽至 12 步，让简单任务一次做对。
- **/api/version 版本端点**：网页版后端提供 `GET /api/version`，返回
  `{"version": "...", "pid": ...}`。曾出现 GUI 失败的根源是陈旧后端进程（旧代码仍在
  内存中运行）——若功能表现与预期不符，先查该端点确认当前跑的是不是最新代码
  （版本号滞后即说明是旧进程，重启后端即可）。
- **常用应用别名扩充**：open_app 的别名表已扩充常用应用——
  网易云音乐 / QQ音乐 / 酷狗 / 抖音 / B站 / 爱奇艺 / 腾讯视频 / Steam /
  钉钉 / 飞书 / QQ / Word / PPT / 迅雷 / 百度网盘等。别名越全，gui_control 的
  自动开路前导（按应用名解析 → 检测窗口 → 自动打开置前）越可靠。

- **TTS 三级链必达**：发声链为 GLM-TTS 男声（智谱 glm-tts，与大脑同一家服务商、
  同一把 API Key，网络稳定）→ edge-tts（`zh-CN-YunjianNeural` 云健男声）备用 →
  Windows SAPI 离线语音（pyttsx3）兜底，逐级自动降级，播报永不缺席；
  仅当三级全部不可用时才静默（此时请检查网络与系统音量）。
- **后端单实例守卫**：网页版后端启动时自动清理占用同一端口的旧进程，再独占
  绑定端口。这修复了「声音等功能时好时坏」的根源——此前预览反复拉起新后端而
  旧后端不死，Windows 允许同端口双绑定，请求被新旧进程随机瓜分；
  现在任何时刻只有一个后端在服务。
- **规则大脑能力有限**：未配置 LLM 时仅支持时间、退出、简单闲聊等固定规则，
  工具与记忆意图靠关键词匹配（`_parse_intent`），复杂说法可能识别不到。
- **记忆是「死记」**：长期记忆为纯文本追加 + 关键词匹配，不做语义检索与去重，
  记得越多 `recall` 播报越长；想精简可对 Nolan 说「忘掉……」或直接编辑记忆文件。
- **提醒时间解析有范围**：仅支持「X 分钟 / X 小时后」「明天早上 / 下午 / 晚上 X 点」
  「X 点 X 分」等常见中文句式；「下周三下午三点半」「每隔一天」这类复杂说法
  解析不了，Nolan 会回引导语请先生换个说法重说。
- **提醒是一次性的**：不做重复规则（每天 / 每周），播报后即删除；
  主循环退出期间到点的提醒，会在下次启动后的首轮检查中补播。
- **软件窗口极简**：GUI 只用标准库 tkinter，无系统托盘、无最小化到后台，
  关掉窗口即退出助手。
- **网页抓取受限**：`fetch_url` 对部分反爬 / 纯 JS 渲染页面拿不到正文。
- 唤醒逻辑极简：仅以「Nolan / 诺兰」开头剥离前缀，无真正的关键词唤醒（KWS）。
- 单轮阻塞式交互，播报期间无法打断（无 barge-in）。
