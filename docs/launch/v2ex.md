**正文：**

```
大家好，分享一个我做了一个多月的开源项目：Nolan。

一句话介绍：对着麦克风说中文，它不光会回答，还会真的动手操作你的 Windows——
开软件、点界面、敲键盘、跑命令、查资料、记事情、定闹钟、按条件主动干活。

仓库：https://github.com/xcq20100224/Nolan
演示：仓库里有无剪辑的真机 GIF——对它说「打开网易云音乐，播放我喜欢列表里的第一首歌」，
它自己调起软件、操作界面、开始播放。

几个我觉得有点意思的设计：

1. 全双工打断，不用回声消除（AEC）
Nolan 播报时你直接开口说话，它就闭嘴听你说。没有用 AEC，而是两道便宜的防线：
自适应能量门（它自己的播报声成为底噪基线，阈值自动抬高）+
回声文本过滤（服务端知道它正在说什么，识别结果和播报文本一比对，是自己的声音就丢弃）。

2. 条件触发
「如果明天下雨就提醒我带伞」「每当有重大 AI 新闻就告诉我」「每隔 30 分钟提醒我喝水」。
条件到点用联网搜索核实真假，成立才行动；动作可以是动嘴（提醒）也可以是动手（直接执行）。

3. 全部能力有实测基准，不拍脑袋
- 300 题单步任务水库、57 题全链路回归（真动 GUI），每次提交必跑 57/57
- 语音识别换代是测出来的：medium→small + 贪心解码，CPU 上快 3.6 倍（1.53 倍实时），
  准确率 92% 持平。有意思的是 medium 配贪心解码是个坑（准确率崩到 55%，中文全变繁体），
  不测就踩进去了。

技术栈：GLM-5.2 Agent 循环（14 个工具）、faster-whisper 本地识别、GLM-TTS 男声、
pyautogui + GLM-4.5V 屏幕感知、React 网页版。MIT 协议，本地优先，数据不出电脑。

诚实声明边界：
- 依赖智谱 API（免费额度够用，但要自己申请 key）
- 只支持 Windows（GUI 自动化部分是 pyautogui + Windows 媒体键）
- 复杂 GUI 操作还不是 100% 可靠，靠技能固化越用越稳

求 star，更求试用反馈和 issue。语音 + GUI 自动化这条路上坑非常多，评论区随便问。
```
