我用第一性原理造了个“贾维斯”：说一句话，它替你操作电脑（已开源）

AndrewMcCain
2026-07-28 10 阅读5分钟

钢铁侠里，托尼说一句"Jarvis, open the garage"，门就开了。

回到现实，你对任何一个"AI 助手"说一句"帮我打开网易云音乐，放我最喜欢的歌"，它会回你一段礼貌的文字：好的，我来帮您——然后告诉你第一步点哪里、第二步点哪里。

差距不在智商，在执行力。 它能不能真的动鼠标、开软件、写文件？

我想要的是一个能"干事"的助手，而不是一个能"聊天"的顾问。市面上没有，所以我照着马斯克的第一性原理，自己造了一个，取名 Nolan，今天开源：

github.com/xcq20100224…

一、第一性原理：一个语音助手最少需要什么？

马斯克造火箭的思路是：不看"火箭本来长什么样"，只问"物理定律要求的最低配置是什么"，其余全砍。

用同样的刀法切一个语音助手，不可约减的要素只有四个：

  1. 听得清——把语音变成文字（ASR）
  2. 想得明白——理解意图并规划动作（LLM Agent）
  3. 做得成事——能操作这台电脑的一切（本机工具链）
  4. 说得出声——有自己的声音回复你（TTS）

其余全是赘肉。Electron？砍，浏览器就是界面。用户系统？砍，这台电脑只有我一个主人。数据库？砍，JSON 文件足够。后端框架？砍，Python 标准库 http.server 够了。

砍完之后，每个要素选最短路径实现：

要素方案为什么
耳朵本地 faster-whisper（medium，CPU int8）语音不出本机，断网也能用
大脑智谱 GLM-5.2 Agent 循环 + 14 个本机工具免费额度够个人用，工具调用稳
双手pyautogui GUI 自动化 + 文件/提醒/记忆工具像人一样看屏幕、动鼠标，不是写死的脚本
嘴巴GLM-TTS 男声 → edge-tts → 离线 SAPI 三级链任何一级挂了都还有声音，声音不能缺席
脸React + Vite 网页 + Python 标准库后端一个 install.bat 全装齐

二、它能干什么（全部真机实测）

「打开网易云音乐，播放我喜欢列表里的第一首歌」——它自己调起软件、移动鼠标、点击播放，像你亲手操作一样。视觉冲击最强的一个：你能亲眼看着鼠标自己动。

「搜一下今天的人工智能新闻，总结三条写到 日报.txt」——这不是预设脚本，是它现场理解需求、联网搜索、提炼、写文件的多步执行。

「1 分钟后叫醒我」——到点后音箱连播两遍（闹钟的价值在于必被听见），实测闭环 100% 可靠。人人用得上的功能。

关键是：这三件事没有一件是写死的流程。它背后是 Agent 循环——理解、规划、执行、验证，再执行。你说一件我从没教过它的事，它也会尝试拆解着去做。

三、三天卡死一个 bug：我是怎么用"黑匣子"破案的

这是整个开发过程里最有价值的一段，值得单独讲。

语音输入功能上线后，出现了一个幽灵 bug：点麦克风，页面永远卡在"正在启动麦克风"。间歇性——有时又好，重启有时有用有时没用。

我排查了三天，每次"修复"都看似合理：POST 换 GET、加 8 秒超时、绕过代理直连、给 TTS 加硬超时……全都没用。

诊断日志显示一个诡异的事实：用户的每次点击，后端都收到了、录音都开始了、响应都发了；curl 和 node 模拟请求，全部秒回。 链路每一环单独测都是好的，但页面就是卡住。

猜到这里，我做了整个项目里最正确的一个决定：停止猜测，先让系统可观测。

我给前端装了一个"黑匣子"：每一步（点击、发起请求、收到响应、轮询状态）都用 fire-and-forget 的方式上报到后端落盘——这种上报只依赖"请求能到达"，不依赖响应，所以哪怕前端网络栈全灭，痕迹也能留下来。

下一次卡死，日志一分钟破案：

点击-开始录音 ✓
micStart 响应 status=200 ✓   ← 响应明明回来了！
（然后……没有然后了，状态轮询日志一条都没有）

请求和响应全部正常，但流程在收到成功响应之后凭空消失。代码里那个位置唯一的出口是：

if (unmountedRef.current) return  // 组件已卸载？静默丢弃

真相：项目用了 React <StrictMode>，它在开发模式会对每个组件做一次"模拟卸载"演练（setup → cleanup → setup）。cleanup 把 unmountedRef 置成 true——而没有任何地方把它复位。ref 随组件实例存活，于是这个标记永远是 true，每一次启动录音在成功之后，都被当作"组件已卸载"静默丢弃。

修复只有一行：在 effect 的 setup 里 unmountedRef.current = false。

教训比 bug 本身值钱： 当你连续两次"修复"都失败时，说明你的模型是错的。这时候不要修第三次——先给系统装黑匣子，让真相自己走出来。

四、10 分钟跑起来

git clone https://github.com/xcq20100224/Nolan.git
cd Nolan
install.bat        # 自动建环境、装依赖、生成配置模板

然后去 智谱开放平台 免费申请一个 API Key，填进 jarvis/llm_config.json，双击 Nolan-Web.bat，浏览器打开 http://localhost:7100 。

点 🎤（或按一下 Alt）说话，再点一次停止。也可以直接打字。

五、Roadmap

  • 屏幕感知：让它真正"看见"屏幕内容，而不只是按坐标点击
  • 唤醒词：随时叫一声"Nolan"就醒，不用点按钮
  • 插件体系：每个人都能给 Nolan 装新技能

100 star 之前我只做一件事：打磨"陌生人 10 分钟跑起来并天天用"的体验。

最后

贾维斯打动人的从来不是它多聪明，而是它可靠——你说的话它一定听见，听见的事它一定去做，做的事一定有回音。Nolan 离贾维斯还很远，但方向是对的。
