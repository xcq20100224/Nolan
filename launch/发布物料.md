## 一、Show HN（英文，Hacker News）

**标题：**
Show HN: Nolan – Open-source, local-first voice assistant that operates your Windows PC (in Chinese)

**正文：**

Hi HN! I built Nolan, an open-source voice assistant inspired by Jarvis. You speak one sentence in Chinese, and it actually does things on your Windows machine — not just chat.

Three things it does out of the box (all demos on the repo page):

1. "Open NetEase Cloud Music and play the first song in my favorites" — it moves the mouse and operates the GUI itself, like a human would.
2. "Search today's AI news and write a 3-line summary into daily.txt" — multi-step, on-the-fly reasoning, not a scripted macro.
3. "Wake me up in 1 minute" — a 100% reliable alarm loop with voice.

Architecture (deliberately boring, first-principles style):

- Brain: Zhipu GLM-5.2 agent loop with ~14 local tools (GUI automation via pyautogui, file ops, reminders, long-term memory).
- Ears: local faster-whisper (medium, CPU int8) — no cloud ASR.
- Mouth: GLM-TTS male voice → edge-tts → offline SAPI fallback chain.
- Face: React + Vite web UI, Python stdlib HTTP backend. No Electron, no framework bloat.

The hardest bug we fixed: voice input silently dying because React StrictMode's simulated unmount poisoned an unmountedRef that was never reset — every successful recording start was silently discarded. We added a "black box" fire-and-forget client-log channel to the backend to catch it. Full story in the commit history.

Local-first: your API key, memory, and audio stay on your machine. Windows only for now. Install is one install.bat + a free Zhipu API key.

Repo: https://github.com/xcq20100224/Nolan

Happy to answer anything — especially about the GUI-automation agent loop and the debugging journey.

**正文：**

一直想要钢铁侠里贾维斯那种助手：说一句话，它就真去干活，而不是给你一段文字建议。市面上的"AI 助手"大多止步于聊天，所以我自己写了一个，今天开源。

**它能干什么（都是真机实测，不是 PPT）：**

**架构（刻意无聊，第一性原理）：**

- 大脑：智谱 GLM-5.2 Agent 循环 + 14 个本机工具（pyautogui GUI 自动化、文件、提醒、长期记忆）

## 三、掘金（中文长文，标题备选）

**标题（三选一）：**
1. 我用第一性原理造了个"贾维斯"：说一句话，它替你操作电脑（已开源）
2. 三天卡死一个 bug，我用"黑匣子"破案后，把这个语音助手开源了
3. 不动手，只动嘴：开源中文语音管家 Nolan 的诞生记

**正文提纲（成稿约 2500 字，发布前可让我扩写）：**

1. **开头（钩子）**：钢铁侠里托尼说"Jarvis, open the garage"，门就开了。现实中的"AI 助手"却只会说"好的，我来帮您"然后给你一段文字。差距在哪？在于**执行力**——能不能真的动鼠标、开软件、写文件。

2. **第一性原理拆解**：一个语音助手的不可约减要素只有四个——听得清（ASR）、想得明白（LLM Agent）、做得成事（本机工具链）、说得出声（TTS）。其余全是赘肉：Electron？砍。用户系统？砍。数据库？砍。

3. **架构图 + 每个模块三句话**（GLM-5.2 Agent 循环 / faster-whisper 本地识别 / 14 个本机工具 / 三级发声链 / React 网页界面）。

4. **最精彩的部分——破案故事**：语音输入卡死三天。请求日志显示后端全部收到并处理，curl 全部秒回，但页面永远卡在"正在启动麦克风"。换了 GET、换了超时、换了直连，全没用。最后给前端装了一个"黑匣子"——每一步都 fire-and-forget 上报后端落盘。日志一出，真相大白：请求和响应全部正常，是 React StrictMode 的模拟卸载把组件的 unmountedRef 永远污染成 true，每次启动成功后都被当作"组件已卸载"静默丢弃。一行复位修复。**教训：先让系统可观测，真相自己会走出来。**

5. **30 秒演示**（GIF：一句话让鼠标自己动起来放歌）。

6. **快速开始**：clone → install.bat → 填智谱 Key → 打开网页。四步，10 分钟。

7. **Roadmap**：屏幕感知、更多平台、插件体系。以及开源计划：100 star 之前只打磨产品。

8. **结尾**：仓库链接 + 求 star 求反馈 + "你最想动嘴解决的那件事是什么？"
